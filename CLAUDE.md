# Pokyny pre prácu v tomto repe

- Po každej práci na indikátore na konci odpovede vždy priložiť hotový `.pine` súbor (SendUserFile) a dať Raw odkaz na GitHub, nech používateľ nemusí kód hľadať.
- Kód sa do TradingView vkladá cez GitHub Raw. Náhľad v chate sa orezáva pri cca 16 000 znakoch, preto každý skript začína poistkou „KÓD JE NEÚPLNÝ" hneď za `indicator()` a končí riadkom `// KONIEC SÚBORU – …`.
- Pine Script v6, štruktúra sekcií Settings → Types → Functions → Methods → výpočty → Plots → Alerts → Dashboard. Texty v dashboarde po slovensky, názvy vstupov po anglicky, tooltip pri každom vstupe.
